# Healthcare Clinic Landing Page

A modern, responsive clinic website designed to help patients discover services, meet doctors, and book appointments quickly.

[View the live demo](https://clinic-demo-peach.vercel.app)

## Highlights

- Service and specialist-doctor profiles
- WhatsApp appointment booking
- Clinic statistics, testimonials, and FAQs
- Timings and location sections
- Mobile-friendly navigation and responsive layouts
- Smooth reveal animations and accessible content structure

## Stack

`HTML` · `CSS` · `JavaScript` · `Font Awesome`

## Run locally

Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000
```

This is a portfolio demonstration; the clinic name and content are illustrative.
